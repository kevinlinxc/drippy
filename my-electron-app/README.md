# My Electron App

A simple Electron application.

## Setup

1. Install dependencies:
```bash
npm install
```

## Running the App

To run the Electron app:

```bash
npm start
```

This will launch the Electron application window.

## Project Structure

- `index.js` - Main process file (Electron entry point)
- `index.html` - Renderer process HTML file
- `package.json` - Project configuration and dependencies

## Development

The app uses Electron to create a desktop application with web technologies (HTML, CSS, JavaScript).
